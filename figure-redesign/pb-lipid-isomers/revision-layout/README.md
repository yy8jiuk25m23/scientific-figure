It is not the earliest A/B schematic containing m1/m2/n1/n2 and the calibration ratio. Those references cannot be silently combined under the user's unique-reference requirement.

The earliest schematic is visible only as a small inline chat image; no original file is available to retain chemical structure regions reliably when a reconstruction is uncertain. Before chemical revision, the correct reference must be identified and supplied as a file if preservation of original uncertain regions is required.
